# Bankamatik

JavaScript ile yazılmış basit bir bankamatik (ATM) simülasyonu. Para yatırma ve çekme mantığını, DOM manipülasyonu kullanarak gerçekleştirir.

## Kullanılan teknolojiler

HTML5, CSS3, JavaScript (vanilla)

## Nasıl çalıştırılır

`bankamatik.html` dosyasını bir tarayıcıda açman yeterli.
